# 0022. Report order comes from the printed copy

Status: accepted, 19 November 2026.

Within a sitting, `report.speech_number` often disagrees with the order Parliament printed the reports in: for pairs of reports it agrees about 61% of the time from 10 September 2012 and about 54% before, and 80 sittings hold two reports with the same number. The order now comes from Parliament's own copy of each sitting, stored on the report as `printed_place`, with the rule that found it in `printed_place_rule`. From 10 September 2012 the copy is the sitting's section list (`sitting.sections`) and the place is the position of the report's section; before that the copy is the sitting's full text (`sitting.html_full_content`) and the place is the word offset of the first 12-word run of the report's text found there once and in no other report of that sitting. A run another report also holds proves no match, and an older report is often printed in pieces with other reports between them, so the place is that of its first piece. An assent report with no text takes place 0, because Parliament's full report prints the assents before every section (checked on 20 November 2026 in the SPRS full-report page, since newer sittings have no printed PDF). A report no rule places stores `NULL` and sorts after the placed reports of its sitting by `speech_number`. `speech_number` stays as the API gave it, so sorting on it again undoes the change, and a stored place is a position in a copy fetched once, so a report added later never moves another.
