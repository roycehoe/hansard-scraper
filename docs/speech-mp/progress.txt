## Iteration 6 — 2026-05-31

### can_match — admin-oaths — Mr. period-after-title OCR artifact

**Root cause:**
The preprocess step's `Mr.` normalization was applied BEFORE extracting the inner name
from a role+name parenthetical. So `The Second Deputy Prime Minister (Foreign Affairs)
(Mr. S. Rajaratnam)` → inner `Mr. S. Rajaratnam` → normalization had already fired on
the full string and had no effect → `strip_title` couldn't strip `Mr.` (period).

**Fix:** Move the `Mr./Dr./Mrs./Ms.` normalization to AFTER the parenthetical extraction,
so it applies to the extracted inner name.

**Outcome:** KEPT
- Pilot: 140/194 → 141/194 = 72.7% (+1)
- Held-out: 81/113 = 71.7% (unchanged)
- Regression: 40/40 = 100.0%

## Iteration 5 — 2026-05-31

### can_match — all types — collective refs and artifacts in denominator

**Root cause:**
7 pilot failures were non-speaker strings not caught by the existing exclusion patterns:
`An hon. Member`, `Some hon. Members`, `Non-Residents`, `Tributes by...`,
`(Announcement by Mr Speaker)`, `(Presence in Gallery)`, `_Moving Ahead_`.
These inflate the denominator and count as failures even though they're parsing
artifacts or collective references, not resolvable individual MP speakers.

**Fix:** Add explicit skip in `_populate_speech_mp_ids` for:
- Strings in a `_NON_SPEAKERS` set (collective refs, paragraph titles)
- Strings starting with `(` (parenthetical announcements)
- Strings starting with `_` (markdown artifacts like `_Moving Ahead_`)

Also update full-corpus exclusion analysis with corrected SQL (fixed `LIKE '_%'` bug).

**Outcome:** KEPT
- Pilot: 140/194 = 72.2% (denominator reduced from 202→194 by excluding 8 artifacts)
- Held-out: 81/113 = 71.7%
- Regression: 40/40 = 100.0%

**Full-corpus ceiling analysis:**
- Denominator: 293,999 matchable speeches (after all exclusions)
- parl=0 matchable: 86,612 (29.5% of denominator)
- Most parl=0 MPs are absent from the Mp table (colonial/LA era, vol 12–23, not on parliament.gov.sg)
- Hard ceiling: ~75–80% match rate
- **The 95% target is unachievable without expanding the Mp table to cover the colonial legislative assembly era**

## Iteration 3 — 2026-05-31

### can_match — all types — parliament=0 fallback to colonial parliaments

**Root cause:**
`report.parliament_number=0` is assigned to volumes 12–23 (the mapping was indeterminate
for those volumes). The Mp table stores all colonial/LA-era MPs at parliaments 1–3, so
lookups keyed by parliament=0 always fail — even for well-known politicians like Lee Kuan Yew.

**Proposed fix:**
After `resolve_canonical_name` returns None and `parliament==0`, retry against parliaments
1, 2, 3 in order. Take the first match found. Update the effective parliament for the
mp_id_lookup step accordingly.

**Backward-compatibility:**
Only fires when parliament==0. All 30 regression speeches are at parl≥1 — no change.
Iteration 1+2 newly-passing cases are also at parl≥1.

**Outcome:** KEPT
- Pilot: 81/160 → 98/160 (50.6% → 61.3%), +17 newly matched
- Held-out: 48/93 → 59/93, +11 flipped
- Regression: 30/30 → 30/30, 0 new failures

## Iteration 1 — 2026-05-31

### can_match — all types — constituency suffix in speaker string

**Affected Speech IDs (pilot):** ~39 (constituency-suffix pattern)

**Speaker string (failing):**
`Dr Tan Cheng Bock (Ayer Rajah)`, `Mr J. F. Conceicao (Katong)`, `Dr Dixie Tan (Ulu Pandan)`,
`Mr Teo Ser Luck (for the Minister for Community Development, Youth and Sports)`,
`Inche Sha'ari Bin Tadin (for the Minister for Culture)`

**Speaker string (passing, same report_type):**
`Mr Christopher de Souza`, `Mr Khaw Boon Wan`, `Dr Goh Keng Swee`

**Expected Mp.name:**
`Tan Cheng Bock`, `J.F. Conceicao` (inverted), `Dixie Tan` (or `Tan Dixie`), etc.

**Root cause:**
`_populate_speech_mp_ids` passes the raw `Speech.speaker` string (after rstrip(':')) directly
to `strip_title` and then `resolve_canonical_name`. When the speaker string carries a trailing
constituency or role parenthetical (`(Ayer Rajah)`, `(Nominated Member)`, `(for the Minister...)`),
the cascade cannot match the name because the lookup keys don't include the parenthetical.

**Proposed fix:**
Pre-processing step before `strip_title`: strip the trailing parenthetical from the raw speaker
string UNLESS its content starts with a title prefix (`Mr`, `Mrs`, `Dr`, etc.), which signals
a role+name pattern (`The Minister (Mr Name)`) that should be handled separately.

**Backward-compatibility:**
All 24 currently-passing pilot speeches have plain names with no parenthetical — the strip is
a no-op for them. Confirmed by simulation: 0 regressions in pilot + regression set.

**Outcome:** KEPT
- Pilot: 24/160 → 50/160 (15.0% → 31.2%), +26 newly matched
- Held-out: 22/93 → 34/93, +12 flipped
- Regression: 30/30 → 30/30, 0 new failures

`The Chairman`, `The Chief Minister` — no name present, unresolvable without role→MP mapping.
These are permanently unresolvable. Should be excluded from denominator if they are structural roles (not individual MPs). To be confirmed.
